## 本轮新增和修正

- 录屏系统事件：使用 WTS 当前会话通知及电源通知。熄屏、锁屏、用户／远程会话断开时自动暂停，解锁／亮屏不会自动继续；原来已经暂停时不覆盖说明。睡眠通知发起停止与保存。倒计时或异步启动中遇到这些事件则取消启动。结束和失败时注销监听。
- 控制条：计时右边显示自动暂停原因，字号 12、次要文字颜色；继续后清除。说明改变宽度时重新测量，按工作区约束位置；暂停时停掉控制条的计时刷新。
- 录屏启动：等待 WGC 提供首个有效画面后才创建写入器；初始化期间不把其他帧入队。保留一个启动首帧作为完全静止画面的保底，随后释放该临时引用。取消启动会停止采集并回收自身未完成文件。
- 暂停尾帧：暂停后不再更新待写出的最后画面，停止时使用暂停前的最后有效帧，避免锁屏后的画面被当作尾帧写入。
- 长截图期间再次按录屏快捷键可以停止已在录制的会话；不绕过互斥去启动新的录屏。
- 长截图启动取消：增加开始前与显示界面后的结束检查，保存局部取消令牌；WGC 的取消和原生对象释放继续由既有流生命周期负责。
- 退出等待：录屏启动结束通过 TaskCompletionSource 通知，替代原先每 25 ms 检查一次的等待。
- 凭据：设置界面只查条目元数据判断已保存，不读取或回填 Key、Secret、ID。空输入提示“已保存 · 输入新的值替换”，每项提供“清除”；空白保存保留旧值。实际翻译读取过的值在本次运行缓存，保存／删除更新缓存，退出清理缓存引用。
- 服务配置：Base URL、模型名、地域进入普通设置的固定字段；只有机密留在 Windows 凭据管理器。旧版非机密配置在启动时迁移，先确认设置保存成功再移除相应旧凭据项，不读取其他机密字段。
- 引擎选择：默认引擎只列已启用且配置齐全的服务；没有可用引擎时显示未配置状态。在线翻译详情优先显示已启用服务。清除某个必填凭据会关闭该引擎；清除凭据保留普通配置。
- OCR：复用独立子进程，以仅当前用户可访问的命名管道传输合成／用户选区的像素与识别结果，图像不落盘。空闲等待使用一次性 30 秒超时，到期退出；取消进行中的识别会关闭对应工作进程。Job Object 管理子进程，主程序退出时一起结束。按需启动同一单文件的 `--ocr-worker` 角色，保留单 EXE 交付。
- 翻译会话：开始新的选区时关闭旧的未钉住结果，立即取消其识别／翻译等待；钉住结果继续保留。原有翻译链路本来就由异步任务／回调驱动，没有添加等待译文的轮询。
- 光标：移植 2.3 的细长等腰三角，底边 6.6、高 7.2、两边各离中心 2.2，方向和深浅语义保持不变。
- 发布构建：Release 使用 DebugType=none，Debug 继续保留嵌入式调试符号。

## 仍缺失或有条件保留的部分

- 设置／欢迎页仍在主进程。本版已使用 WPF 创建托盘消息窗口、截图和控制条，设置拆分收益需要测量。新提示词明确要求“先量再决定”；本轮由用户测试，未做前后内存对比，因此保留现状，不声称已经实现 VelosSettings 或节省了多少内存。
- 内存回落和重复操作泄漏尚未测量。本轮检查了现有按钮的 DependencyPropertyDescriptor 外部订阅在 Unloaded 时撤销、窗口关闭时解除主窗口引用；.NET 可以回收一般事件循环引用，不能据此声称不存在其他泄漏。
- 二维码识别仍未实现，设置仍明确禁用；Windows 没有 Apple 系统离线翻译／词典，对应能力继续使用 Windows OCR／语音和配置的在线引擎。
- 真实 Windows 10、真正 32 位系统、混合 DPI 多屏、系统事件／睡眠保存、OCR 复用和旧配置迁移都待用户运行验收。本轮没有内存或 CPU 实测数字，不引用旧版本采样冒充当前结果。
- 2.3 的界面参考图片与 2.2 相同，仍标注 2.1.2；本轮新增逻辑以 Swift 2.3 源码及更新说明为依据，未进行新的截图对照验收。
