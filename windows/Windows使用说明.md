# Velos Windows 使用说明

适用于 3.0.0 预览版，Windows 10 2004 或更新。64 位 Windows 推荐下载 x64 ZIP；32 位 Windows 使用 x86 ZIP。没有 ARM 构建。

## 开始使用

可先运行发布页的 `Velos-Windows-Downloader.exe`，自动推荐 x64 或 x86，选择保存位置后下载 ZIP。下载器会校验文件完整性，完成后可打开所在文件夹；不会自动执行程序。也可直接下载对应 ZIP。

1. 将 ZIP 完整解压到一个固定文件夹，再运行 `Velos.exe`。无需安装 .NET，也无需管理员权限。
2. 本版没有代码签名。若 Windows SmartScreen 显示「Windows 已保护你的电脑」，确认文件来源后，选择「更多信息」→「仍要运行」。组织策略可能禁止继续，这时需要联系电脑管理员。
3. 首次运行显示欢迎页，之后常驻托盘并静默启动。左键单击托盘图标直接打开／恢复设置界面，右键打开原有菜单，可截图、录屏、截屏翻译、设置或退出。关闭窗口不会退出程序；隐藏托盘后再次运行 EXE 可回到设置。
4. 可在「设置 › 通用」中启用登录启动。移动 EXE 后需要重新开关一次登录启动；设置中的快捷键冲突会明确提示，换成可用组合即可。
5. 设置右上角从左到右为最小化、最大化／还原、关闭。图标始终显示，最大化后中间按钮变为还原，支持键盘焦点和 Alt+F4。
6. 截图、录屏的保存路径保持单行，随窗口宽度自动分配空间；路径过长时省略，悬停查看完整路径。自定义目录后显示“恢复默认”。

preview.19 的设置开关采用圆钮滑动和轨道渐变；鼠标点击不显示黑色虚线。使用 Tab／空格时会显示细暖色圆角焦点环。按钮悬停保持尺寸，胶囊按钮仅在按下时轻微收缩；侧栏选中底座、分段选择和缩略图分别按 Mac 的动效处理。系统关闭界面动画或开启高对比时直接切换状态。

更新时先从托盘右键菜单退出旧版，再运行新版 EXE；已经运行的旧版会接收重复启动请求并显示它自己的设置窗口。

## 截图与长截图

默认按 `Alt+A` 冻结屏幕。拖动框选，或单击识别到的窗口；选择后可拖动控制点、移动选区，方向键可微调。再次按 `Alt+A` 切换区域／全屏，`Esc` 取消，`Enter` 完成。

工具栏提供矩形、椭圆、箭头、直线、画笔、荧光笔、文字、序号、马赛克和模糊。按住 Shift 可约束形状和角度；属性栏调整颜色、透明度和粗细。`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Ctrl+C` 复制，`Ctrl+S` 保存。截图可通过缩略图编辑、保存、复制、拖出或钉到屏幕上。编辑器中 `Ctrl++`／`Ctrl+Shift+=` 放大到当前的 125%，`Ctrl+-` 缩小到 80%，`Ctrl+0` 恢复自动适配，`Ctrl+W` 关闭。

文字输入时可实时调整颜色、字号、底色和透明度；Enter 确认文字，Shift+Enter 换行，Esc 保留文字并结束输入。文字不自动折行，点击的位置保持为左上角。自定义颜色提供实时调色盘，可输入 `#RRGGBB`、`#RGB`、`#RRGGBBAA`、`rgb(...)` 或 `rgba(...)`，八位颜色最后两位是不透明度。调色盘外点击或按 Enter／Esc 关闭，保留已经应用的修改。

选好区域后，尺寸标签旁的「圆角」拉条可在 0–40 点调整，也可滚轮微调，设置会记住。全屏截图保持直角。PNG 保留透明角，JPEG 圆角外填白；Windows HEIC 无法保证透明时会保存为实际的 PNG 文件。编辑圆角截图时保持透明和随形投影。

选好区域或全屏且没有标注时，点长截图按钮，在选区内向下滚动。预览跟随当前位置，回滚不会重复接图；控制条提供编辑、钉图、保存和完成。当前长截图只提供纵向，手动滚动不读取或拦截鼠标输入。滚得太快丢失重叠后可往回滚；持续稳定向前滚动时，会跳过漏掉的段再继续，未采到的内容不会被补造。

点「自动滚动」可持续滚动，再点「停止」关闭。鼠标移出选区暂停、移回继续；在能滚动的同一位置停留到底约 1.2 秒，或达到 20,000 像素上限时停止。不会移动鼠标指针。支持高精度滚轮的应用会更平滑，部分程序的步长由自身决定；不能向管理员窗口发输入时会提示，请改用手动滚动。

长截图的导出和复制始终保留原生物理像素，不受「按 1x 分辨率输出」影响。编辑器／钉图支持原生比例与滚动查看。普通截图的输出格式、1x、复制、自动保存和缩略图分别在「设置 › 截图」控制。默认保存到系统「图片」中的 `ScreenShots`。

编辑器下方常驻显示原图宽×高和缩放比例。点「100% 原像素」或按 `Ctrl+1`，以一个屏幕物理像素显示一个图片像素；点「适合窗口」或按 `Ctrl+0` 恢复适配。侧边长图预览是缩小的预览。要求文字像素无损时选 PNG；JPEG／HEIC 保存仍受压缩格式影响，像素宽高不会因此被缩小。

## 钉图缩放

普通钉图把鼠标放在图片上直接滚轮缩放，鼠标所指的图像位置保持在原处。移到四边或四角时显示暖色双三角光标，按住左键拖动也可等比缩放，对边或对角固定。不显示白色缩放控制点；图片内部拖动仍用于移动窗口。缩放按键与捏合没有新增。

长图内部普通滚轮用于翻看，按住 Alt＋滚轮缩放；Ctrl＋滚轮调整透明度。沿长轴拖单边只改变露出的范围（竖图上／下边、横图左／右边），像素比例保持不变；拖短轴边或角才缩放。正在拖边或移动窗口时，滚轮不改写本次拖动的尺寸和起点。

钉上后自动选中，无需先点击；普通图片在屏幕放得下就原尺寸、原位显示，超出屏幕才适配。长图保持原宽度／高度，初始视口长轴最多占工作区 85%。右键菜单可恢复「原始大小」、查看当前比例、复制、另存或调整透明度。拖边过程中 Esc 撤回这次缩放；平时双击或 Esc 关闭钉图。

## 录屏

按 `Alt+S` 打开实时选区，框选区域或再次按快捷键选全屏，点「开始录制」。选项条可以更改系统声音、麦克风及设备、鼠标指针和帧率；在设置中可以选择原生／1080p、60／30 fps、HEVC／H.264 和画质。

录制时，控制条显示累计录制时长，可以暂停／继续、麦克风静音和停止；再次按 `Alt+S` 也会停止。暂停的时间会从视频中扣除。红框与录屏控制条从采集中排除；截图界面、标注、翻译结果、缩略图和钉图会出现在录屏中。启用点击高亮后，左键显示杏色圆圈，右键显示珊瑚色圆圈，它们会录进视频。

屏幕熄灭、锁屏或会话断开时会自动暂停并在控制条上说明原因，亮屏／解锁后保持暂停，由你点“继续”。睡眠通知会发起停止与保存，完成后显示缩略图；系统留给写入器的时间由 Windows 决定，收尾可能延续到唤醒后。录屏启动或倒计时中遇到这些事件会取消启动。长截图期间仍可用录屏快捷键停止已在进行的录屏。

可在设置中开启 3 秒倒计时；倒计时期间 `Esc` 或再次按录屏快捷键取消，`Enter` 立即开始。系统或麦克风无法采集时会提示，失败声源作为静音继续保存视频。若权限受限，请检查 Windows 设置 › 隐私与安全性 › 麦克风，以及声卡输出设备。

录屏自动保存到系统「视频」中的 `ScreenRecordings`，格式 MP4，音轨为 48kHz 立体声 AAC。原生模式只裁掉不满足编码要求的最后一行／列奇数边缘。HEVC 不可用时提示回退 H.264；有的播放器需要另装 HEVC 支持，可以直接选 H.264 获得更广兼容性。

完成后的缩略图可以预览、拖出文件、复制文件、导出 GIF 或移到回收站。GIF 转换显示进度，可取消；GIF 保存在视频旁边，保留原视频，不覆盖同名文件。在「设置 › 录屏」中还可选之前的视频转 GIF，并调整 GIF 帧率与最大宽度。

## 截屏翻译

结果窗口的标题栏空白、卡片留白和外侧内边距可以按住拖动；未钉住时最外层边缘留白也可拖动，文字区域用于编辑／选择。图钉或 `Ctrl+P` 钉住后可拖动边缘调整大小，再点一次取消钉住。复制后显示独立提示，识别耗时保持不变；朗读时按钮变为杏色停止按钮，再点一次停止。

按 `Alt+D` 框选，松开鼠标后先出现结果窗口，再填入离线 OCR 原文和译文。再次按快捷键切换全屏，`Enter` 确认全屏，`Esc` 取消。没有识别到文字时，窗口提示后自动关闭。

OCR 完全离线。若提示缺少语言包，打开 Windows 设置 › 时间和语言 › 语言，添加目标语言并安装其光学字符识别／基本键入组件。独立识别进程按需启动，空闲 30 秒退出，Velos 退出时一起结束；空闲时不采集屏幕。当前不支持二维码解码。

Windows 没有系统离线翻译。本版支持腾讯、火山、百度、有道、DeepL、微软、OpenAI 兼容接口和 Claude。请在设置中选服务商，可先启用该引擎，再填写自己的字段并点「保存」。缺少配置时开关保持开启，旁边提示缺项；补齐前不会发送请求，测试按钮保持禁用。Key、Secret 和 ID 存在 Windows 凭据管理器；地址、模型和地域保存在普通设置 JSON。已保存的机密不回填到输入框，只提示“已保存 · 输入新的值替换”；留空保存会保留旧值，点旁边的“清除”删除对应项。未启用、配置不全时不会联网。保存和测试结果显示在当前引擎下方；切换服务商保留本窗口未保存草稿，关闭后只读取已保存配置。「测试」只在引擎已启用且配置完整时发送 `Hello Velos` 文字。关闭引擎会取消正在进行的请求。

更新后，旧版放在凭据管理器中的地址、模型和地域会迁到普通设置，保存成功后才移除对应旧项。默认引擎只列出已启用且配置完整的服务；没有可用服务时显示未配置状态。

OpenAI 兼容接口填写 Base URL、模型和 API Key，程序自动补 `/chat/completions`；DeepL 免费 Key 以 `:fx` 结尾；腾讯地域留空使用 `ap-guangzhou`，微软全局资源的区域可留空。默认引擎失败时只尝试其他已启用且凭据完整的引擎。请求只含原文、语言和必需协议字段，不含截图；不上传日志或统计数据。

可直接编辑原文，停顿 0.6 秒后重新翻译；等待新译文时旧结果变淡，首段新结果到达后替换。大模型流式结果逐段显示，复制和朗读使用实际译文；清空原文会立即清除旧译文并取消在途翻译。可切换或交换语言；默认中文译成英文，其他语言译成简体中文。点钉住按钮可保留多个结果窗口并调整大小；未钉住的窗口在鼠标点击窗口外时关闭，单纯 Alt+Tab 失焦不关闭。朗读使用本机系统语音，缺少语音时需在 Windows 语言设置中添加对应的语音包。单词和短语也通过所选引擎翻译，没有 macOS 系统词典卡片。

结果窗口快捷键：`Ctrl+C` 复制译文（选中文字时复制选中部分），`Ctrl+Shift+C` 复制原文，`Ctrl+R` 重新翻译，`Ctrl+P` 钉住／取消钉住，`Esc` 关闭。

## 保存位置与限制

设置位于 `%APPDATA%\Velos\settings.json`；截图和录屏保存在各自设定的文件夹。未保存截图拖入仅接收普通文件的程序时，会在 `%TEMP%\Velos\ScreenshotDrag` 临时生成原生 PNG；查询是否支持拖入不会写文件。再次启动时，会将超过一天的本程序拖拽临时截图移到回收站。内置自动自测只存在于 Debug 构建，正式预览包不含自测入口。

不同 Windows 版本、缩放、显卡／声卡驱动和受保护窗口会影响采集；UAC 安全桌面、DRM 内容或远程会话可能不可采集。优先使用普通桌面窗口和最新驱动。x86 进程内存较少，超长图和高分辨率视频推荐 x64。Mac 的字体、系统图标和模糊材质与 Windows 有平台渲染差异。

程序不会自动更新。更新时先从托盘退出，替换 EXE；自己的截图和录屏不受影响。正式对外发布仍需另行确认。
