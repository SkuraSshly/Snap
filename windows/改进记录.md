## preview.5 历史记录

修复设置空白处被点击后，Alt／Alt+A 导致整个内容区出现黑色虚线的问题。根因为设置 `ScrollViewer` 默认可获得键盘焦点，Alt 激活 Windows 焦点提示后显示系统默认装饰框。页面及下拉列表的滚动容器不再独立接收焦点或 Tab 停靠，内部开关、按钮和列表仍可正常获得焦点、滚动和操作。没有全局吞掉 Alt，也没有取消交互控件的键盘提示。

基础自测增加空白容器不抢焦点、内部开关可获焦点的回归检查。另有 Debug 专用原生 Alt+A 验证模式，通过实际键盘输入确认 Windows 消息已收到且整页装饰框不存在；该模式拦截真实捕获，不采集桌面，Release 不包含它。

本轮针对图标语义、动效和实际操作问题改进，所有改动仅位于 `windows/`。x64 和 x86 为交付目标，无 ARM 构建。

## 动效与界面

- `UI/WarmMotion.cs`：按钮悬停、按压缩放、开关滑动、设置页淡入、工具属性浮现、缩略图进出、复制反馈；跟随系统动画设置，有限时动画结束后释放时钟。修正 WPF 模板冻结变换的加载异常。
- `UI/ActionIcon.cs`：按动作含义统一图标。录屏使用录制图标，暂停与继续、麦克风与静音、播放器音量与静音随状态切换。系统没有合适字形的标注工具使用原创基础几何，避免把对比度当模糊、拨盘当序号、网格视图当马赛克。
- `SettingsWindow.xaml`、`SettingsWindow.xaml.cs`、`Screenshot/SettingsPane.cs`：开关滑动、导航和设置页反馈，纠正录屏、翻译、指针、帧率、分辨率、画质等图标，切页恢复到顶部。
- `Screenshot/CaptureChrome.xaml`：悬停与按压叠层保留选中底色，避免白色图标悬停后失去对比度；翻译小按钮使用参考图中的圆角矩形。
- `Recording/RecordingSettings.cs`：分辨率、帧率、编码、画质改成等宽分段胶囊，避免“高”选项缩成圆点；键盘焦点使用圆角边框反馈。

## 操作修复

- `Screenshot/CaptureSurface.cs`：录屏透明选区内部也参与原生命中测试，避免点击穿透，保留实时桌面显示。
- `UI/Interaction.cs`、`Recording/RecordingChrome.cs`：沿控件树识别按钮和滚动条，避免点击按钮内部图标时启动拖动窗口；同步更新无障碍名称。
- `Screenshot/MarkupToolbar.cs`、`MarkCanvas.cs`：拖动滑块实时预览，一段拖动只产生一次撤销；更改不透明度不会还原刚调整的粗细。失去鼠标捕获或键盘焦点会结束编辑事务。
- `Screenshot/ShotWindows.cs`：长图钉图的滚动条独立接收操作，避免触发拖动窗口。
- `Translation/TranslationWindow.cs`：钉住并扩大窗口后，两张卡片一起伸展；清空原文立即清空旧译文；失败的流式结果不再残留为可复制内容；引擎菜单不会被失焦关闭逻辑误关；关闭期间不再重复触发关闭；补充识别骨架与朗读状态。
- `UI/ThumbnailShelf.cs`、`Screenshot/ShotThumbnail.cs`、`Recording/RecordingThumbnail.cs`：截图和录屏缩略图共用排列，避免重叠；动画重排；录屏时长徽标允许点击穿过到预览；GIF 转换中阻止预览和拖出，关闭会取消转换；播放器按钮显示真实状态。
- `Recording/ClickHighlighter.cs`、`RecordingController.cs`：点击按下时平滑出现；点击高亮初始化失败时保留正在进行的录屏并提示。
- `LongCapture/LongCaptureSession.cs`：拼接丢失时提示慢滚或回滚，长度到上限时明确提示保存，保留已拼接内容。
