# 卸载 Velos Windows

本版为便携应用，没有服务、驱动或系统级安装项。

1. 若启用了登录启动，先在「设置 › 通用」关闭它；然后从托盘菜单「退出 Velos」。录屏中退出会先尝试保存已录制内容。
2. 将解压后的程序文件夹移到回收站。
3. 不想保留设置时，将 `%APPDATA%\Velos` 文件夹移到回收站。
4. 不想保留翻译凭据时，在 Windows「控制面板 › 凭据管理器 › Windows 凭据 › 普通凭据」删除以 `Velos/Translation/` 开头的条目。也可在卸载前，逐个服务商点「清除凭据」。Debug 构建使用独立的 `Velos/Debug/Translation/` 前缀。

如已删除 EXE 才想移除登录启动，可在注册表当前用户 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 中仅删除名为 `Velos` 的值；不要删除整个 Run 项。

截图、录屏及导出的 GIF 不会自动删除。请自行检查保存文件夹，确认不需要后再移到回收站。单文件运行时的 .NET 解压缓存位于系统临时目录下 `.net\Velos`，未保存截图的拖拽临时文件位于 `%TEMP%\Velos\ScreenshotDrag`；确认所有 Velos 进程和接收拖拽的程序都已不再使用这些文件后，也可以将相应目录移到回收站。
