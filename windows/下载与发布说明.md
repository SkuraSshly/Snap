# Windows 下载与发布

本版入口为 [Windows 3.0.0-preview.21](https://github.com/SkuraSshly/Velos/releases/tag/windows-v3.0.0-preview.21)，与 macOS 发布分开。之前 preview.20 的 ZIP 下载器发布已撤回。

下载 **Velos-Setup.exe**，打开后自动识别 x64／x86 并开始下载，校验后完成安装。点击「启动 Velos」即可使用，也可在开始菜单启动。无需手动保存 ZIP 或解压。安装在当前用户 `%LOCALAPPDATA%\Programs\Velos`，不需要管理员权限。

发布附件：

- `Velos-Setup.exe`：推荐入口，小型在线安装程序。
- `Velos-3.0.0-preview.21-win-x64.exe`／`Velos-3.0.0-preview.21-win-x86.exe`：安装器下载的完整自包含程序，也可手动下载直接运行。
- `Velos-Install.json`：绑定此版本的 EXE 下载地址、长度和 SHA-256。
- `SHA256SUMS.txt`：发布附件的完整性校验值。
- `Velos-Windows-Source.zip`：安装器和主程序源码快照；这是源码归档，不是应用安装包。
- `Windows-Verification.md`：安装流程和主程序检查范围。
- `LICENSE.txt`：许可证，安装器也会写入安装目录。

需要 Windows 10 2004 或更新。主程序无需安装 .NET；安装程序使用系统自带的 .NET Framework 4.8。没有 ARM 构建。文件未进行代码签名；SHA-256 校验只验证完整性。升级前从托盘退出旧版，再运行安装程序；原设置和截图保留。

下载失败或取消不会改变已有安装；文件替换、快捷方式或安装记录写入失败时恢复原版本。卸载从 Windows「已安装的应用」进行，也可运行安装目录中的 `Uninstall.exe`。保留截图、录屏、设置和凭据。

安装器只从此仓库的 HTTPS Release 地址获取文件，不查询 GitHub API，不包含账号凭据或遥测。构建与验证见 [安装器源码说明](setup/README.md)。`Package-Setup.ps1` 打包 EXE 和安装清单；Windows build 工作流只构建验证，不自动公开发布。
