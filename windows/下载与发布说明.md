# Windows 下载与发布

本版公开分发入口为 [Windows 3.0.0-preview.20](https://github.com/SkuraSshly/Velos/releases/tag/windows-v3.0.0-preview.20)，与 macOS 发布分开。Windows 仍为预览版，macOS 的 Latest 入口保持原样。

- `Velos-Windows-Downloader.exe`：约 155 KiB，自动推荐 x64／x86，也可手动选择。选择保存位置后下载 ZIP，校验文件大小和 SHA-256，完成后打开文件夹；不会自动启动程序。
- `Velos-3.0.0-preview.20-win-x64.zip`：64 位 Windows 推荐，包含自包含主程序、说明与许可证。
- `Velos-3.0.0-preview.20-win-x86.zip`：32 位 Windows 或需要兼容版时使用。
- `Velos-Windows.json`：此版本下载器读取的发布信息和两种架构的大小／哈希。
- `SHA256SUMS.txt`：发布附件的完整性校验值。
- `Velos-Windows-Source.zip`：对应发布提交的 Windows 源码；GitHub 的 Source code 附件还提供完整仓库快照。
- `Windows-Verification.md`：主程序功能验收、复现、修复与测试范围。

需要 Windows 10 2004 或更新。主程序无需安装 .NET；小下载器使用系统自带的 .NET Framework 4.8。没有 ARM 构建。文件未进行代码签名；SHA-256 校验只验证完整性，不能代替代码签名。升级前从托盘退出旧版，再解压新版并运行 `Velos.exe`。

下载器不查询 GitHub API，不包含账号凭据、不收集遥测，不修改系统设置；只从此仓库的 HTTPS Release 地址下载。失败或取消会清理本次临时文件，已有文件不会在校验失败时被覆盖。

构建步骤及下载器检查见 [下载器源码说明](downloader/README.md)。仓库的 Windows build 工作流负责核心检查、下载器检查、x64／x86 编译和构建产物，不在每次推送时自动发布。
