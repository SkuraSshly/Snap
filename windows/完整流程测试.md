# preview.20：恢复滚轮缩放与完整缺陷检查

按最新要求恢复普通钉图直接滚轮缩放，保留无白点的边缘／四角缩放。长图普通滚轮翻看、Alt＋滚轮缩放，Ctrl＋滚轮调整透明度；短暂显示当前百分比，不新增弹出或回弹。键盘缩放与捏合没有恢复。拖边／移动期间忽略滚轮，防止两套输入同时改写拖动起点。

## 本轮复现与修复

1. **快速长图滚动和缩放丢位移**：`ScrollViewer` 的滚动命令排队执行，后续输入读到旧偏移。六次连续放大复现鼠标下原图位置偏移约 254.34 像素；修改 `PinWindow.ScrollPixels`，在下一次输入前完成滚动布局，普通翻看也使用同一路径。修复后竖／横长图专项锚点误差为 0.00 像素，六次翻看累计 72 DIP。
2. **大图适配低于 10% 后跳档**：核心回归复现初始 4% 的图片，一次放大直接跳到 10%。`PinLayout.Zoom`、`WheelZoom` 与拖边函数支持初始适配下限，窗口保留该下限，能逐步放大并反向回到初始适配比例。通常范围仍为 10%–800%；滚轮最小显示尺寸夹取避免大幅缩小输入整次被忽略，极小图片仍能放大或恢复原像素。
3. **开关轨道反向停顿**：旧轨道颜色每次重建动画都会把速度设为 0，与圆钮不同步。先用实际 WPF 开关复现失败，再将 UIElement 透明度与变换纳入同一弹簧会话，继承位置／速度，结束及卸载时释放时钟。接入过程中中间帧检查曾失败，补全可控时钟的显式启动；该开发中的失败保留日志，不冒充旧版的另一项独立缺陷。设置自测窗口置顶确保可见，并等待实际中间帧，不仅依赖固定 45 毫秒采样。[WPF 时钟控制说明](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/how-to-interactively-control-a-clock)说明了显式时钟及控制器的生命周期。
4. **翻译多窗口朗读串扰**：两个窗口使用相同的 `source`／`translation` 标识；其他窗口也显示“停止”，关闭无关窗口会执行全局 Stop。两项分别由 SP02、SP03 复现失败。现在每个窗口有独立归属，仍共用一条全局语音输出；按钮状态只属于对应窗口，关闭只停止本窗口的会话。测试建立无播放的会话状态，验证实际窗口按钮刷新、关闭事件及重复点击停止，不生成可听声音。

滚轮恢复属于本轮功能变更；上面列出的失败均保留修复前结果，不用旧版通过数字充当新版本验收。

# preview.19 历史记录：修正开关焦点与逐项动效对齐

用户指出开关的运动和黑色虚线框不符合 Mac。本轮以固定 Mac 2.4.2 提交 `00b2437575ba224da7e6b60fc7b20111d9af8b7a` 对照 `SettingsPane.swift`、`SettingsWindowController.swift`、`WarmStyle.swift`、`TranslationView.swift`、`ThumbnailManager.swift` 和点击高亮代码。只修改 Windows 目录，继续构建 C#／WPF x64、x86。

## 原因与修正

- 黑色虚线来自 WPF 默认焦点装饰：`Switch` 样式没有设置 `FocusVisualStyle`，同时 `IsKeyboardFocused` 触发器把轨道描成黑色实线。现在开关使用专属暖色圆角键盘焦点环，删除黑线触发器；应用级默认焦点样式也改成暖色圆角。保留 Tab、空格和辅助功能，鼠标点击不会出现该黑色虚线。
- 开关原先圆钮只有 15 点、行程 13 点，轨道与圆钮还使用不同节奏。现在对应 Mac 36×21 开关，圆钮 17 点、边距 2 点、行程 15 点，配渐变轨道、细阴影及禁用时 0.4 透明度；开关弹簧 `response: 0.30, damping: 0.68`。
- 移除统一的「悬停 1.035 倍、按下 0.94 倍」方案。设置胶囊按钮只在按下时缩至 0.95；翻译小图标按钮缩至 0.94，均用 `0.20 / 0.70`。AppKit 截图／录屏工具按钮按源码只切换底色，侧栏整行和分段标签不缩放。
- 侧栏底座 `0.34 / 0.80`、分段选择 `0.32 / 0.74`；页面仅 0.18 秒 easeOut 淡入，不缩放、位移或动画标题。侧栏只让图标轻微弹动，对应 Mac 的符号 bounce；SF Symbols 的系统动画在 Windows 用有界图标位移近似，不声称跨平台逐帧完全一致。
- 翻译钉住旋转改用 `0.30 / 0.60`，快速反复钉住从当前角度和速度接续；去掉自行添加的窗口弹出缩放、持续闪烁占位、属性面板飞入和钉图提示回弹。钉图提示按 Mac 定时显示／隐藏。
- 缩略图进入和重排改为 0.20 秒 easeOut，不再弹出过冲；关闭淡出 0.15 秒。录制点击高亮按下从 0.5 放至 1，0.12 秒；松开扩至 1.8 并淡出，0.35 秒，使用 easeOut。

`Core/Animation/SpringMotion.cs` 用秒和控件各自的参数计算阻尼响应；`UI/WarmMotion.cs` 在重定向时继承位置和速度，结束后释放时钟，系统关闭动画或高对比时直接赋最终值。[Apple 的 spring 说明](https://developer.apple.com/documentation/swiftui/animation/spring(response:dampingfraction:blendduration:))明确说明后续弹簧动画继承速度；WPF 的渲染与 SwiftUI 不同，因此本轮验证的是源码参数、行为、几何、实际输入与时钟清理，不冒充在 Mac 上同步录制后的逐帧画面对比。

主要文件：`SettingsWindow.xaml`、`SettingsWindow.xaml.cs`、`App.xaml`、`UI/WarmMotion.cs`、`UI/ThumbnailShelf.cs`、`Screenshot/CaptureChrome.xaml`、`MarkupToolbar.cs`、`PinWindow.cs`、`TranslationWindow.cs`、`TranslationCopyHud.cs`、`WelcomeWindow.cs`、`ClickHighlighter.cs`。新增／更新 `MotionReview.cs`、设置和钉图专项及核心数学回归。版本为 `3.0.0-preview.19`／文件版本 `3.0.0.19`。

## 最新 GitHub 发布核对

在线核对 [v2.4.2 发布页](https://github.com/SkuraSshly/Velos/releases/tag/v2.4.2)，并通过 git 读取固定提交 `00b2437575ba224da7e6b60fc7b20111d9af8b7a`；同时对比 v2.4、v2.4.1 与原 v2.3。v2.4.2 的核心修复是截图工具栏钉图后保持选中，v2.4.1 取消窗口外的额外抓取圈。Windows 本版没有增加窗口外边距：窗口矩形就是图片／视口矩形，透明 PNG 内侧仅有低透明度命中带。

同步的行为包括：图片放得下就原位原尺寸，只有超屏才按工作区适配；长图短轴保持原尺寸、初始长轴视口限工作区 85%；沿长轴拖单边只改可见长度、不改像素比例；短轴边和四角才等比缩放，对边／对角固定，角按相对位移较大的方向计算。钉上后自动选中，截图工具栏钉图不再先把焦点还走。Mac 仍提供的滚轮缩放按用户本轮要求在 Windows 移除。

另同步 v2.4 的非拉丁 OCR 候选保护：候选必须保住基准结果中每种非拉丁文字至少九成，防止中文字、假名、谚文等被拉丁乱码替换。Windows 使用自己的离线 OCR 接口，不把 Vision 的可用能力或准确率当作 Windows 实测结论。Mac 新增的程序坞常驻图标是平台特定入口，本轮未照搬该设置；Windows 保持既有托盘左键显示设置、右键菜单与设置窗口任务栏入口。

# preview.17 历史记录：钉图缩放与动效

本轮先实际用滚轮检查普通钉图：100% 可放大至 117%。同时以核心回归复现极小图片不能逐步放大的边界错误（修复前 90／91，修复后 91／91）。不把入口不明显和已验证可用的普通滚轮混称为同一个问题。

## 改动及原因

- `Core/Screenshot/PinLayout.cs`：最小尺寸只限制继续缩小，不阻断小图的逐步放大；仍保持 10%–800% 的交互范围。
- `Screenshot/PinWindow.cs`：右键加入放大、缩小与当前百分比，原始大小显示快捷键；选中钉图后 Ctrl++／Ctrl+- 缩放，Ctrl+0 或 Ctrl+1 回原始大小，无修饰键 +／- 也可用。普通图片滚轮缩放，长图滚轮翻看、Alt＋滚轮缩放；Ctrl＋滚轮继续调透明度。
- 缩放读取当前原生窗口矩形，避免连续输入时读取尚未布局的旧尺寸。长图按鼠标所在的原图位置计算新滚动偏移，缩放后不跳位；窄长图的操作提示可换行，且保留更长时间。
- 钉图百分比提示补淡入、轻微回弹与淡出，重入不会被上一次隐藏回调提前收掉；关闭窗口会停计时和提示动画。图像本体的原生像素与导出数据不做动效重采样。
- `UI/WarmMotion.cs`：按钮按下快速收缩、松手回弹；开关、侧栏、分段选择、页面切换与翻译浮窗使用短时阻尼曲线。中途改目标从当前值接续，通过代数标记防止旧完成事件移除新动画；完成后移除时钟与控制器。系统减少动画或高对比时直接设置结果。
- `UI/ThumbnailShelf.cs`：缩略图位置过渡采用同一回弹曲线，240 毫秒结束后停止计时器；`TranslationWindow.cs` 补轻微浮窗出现动效。`Debug/StageOneSelfTest.cs` 按回弹轨迹核对开关中间值与结束时钟。
- 新增 `Debug/PinInteractionReview.cs`，通过 `ScreenshotSelfTest.cs` 独立运行专项；`ParityTests.cs` 增加极小图片回归；版本为 3.0.0-preview.17／文件版本 3.0.0.17。Mac 源码未改动。
