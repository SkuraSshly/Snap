# 卸载 Velos

Velos 不安装任何后台服务、系统扩展或安装器（截屏翻译用的文字识别小进程 VelosOCR 在 App 里面，随 App 一起删除）。下面列出了它在电脑上留下的**全部**内容，按顺序处理即可卸载干净。

## 第 1 步：关闭开机启动，退出 Velos

1. 菜单栏 Velos 图标 › 设置 › 通用 › **取消勾选「登录时自动启动」**（如果开过）。
   先在 Velos 里关掉，系统的登录项记录会被正常移除。
2. 菜单栏 Velos 图标 › **退出 Velos**。

菜单栏图标被隐藏了？在「应用程序」里双击 Velos 会打开设置窗口；退出也可以用：

```bash
osascript -e 'quit app "Velos"'
```

## 第 2 步：删除 App

把 `/Applications/Velos.app`（或你放 Velos 的位置）拖到废纸篓。

## 第 3 步：删除设置、缓存和临时文件

| 内容 | 位置 | 说明 |
|---|---|---|
| 设置 | `~/Library/Preferences/local.velos.Velos.plist` | 快捷键、保存位置、各项开关（含截屏翻译的设置，见下表） |
| 文字识别模型缓存 | `~/Library/Caches/local.velos.Velos`、`~/Library/Caches/local.velos.Velos.OCR` | 系统的 Vision 框架为截屏翻译编译的识别模型（几百 KB），由系统写入 |
| 拖拽用的临时文件 | `$TMPDIR/Velos`（`/var/folders/…/T/Velos`） | 只在把**未保存**的截图从缩略图拖出去时产生；Velos 每次启动会清理一天前的 |

截屏翻译在设置文件里的项目（都在 `local.velos.Velos` 里，上面的 `defaults delete` 会一起删掉）：

| 设置项 | 内容 |
|---|---|
| `translateHotkey` | 截屏翻译快捷键 |
| `hotkeysMigratedToASD` | 默认快捷键已换成 ⌥A / ⌥S / ⌥D 的标记 |
| `ocrSmartLayout`、`ocrDetectsQRCodes`、`ocrPreferredLanguage` | 文字识别选项 |
| `ocrFullWarmUpBuild` | 已为哪个系统版本预先编译过识别模型 |
| `enabledEngines`、`defaultEngine`、`llmPrompt` | 启用的在线引擎、默认引擎、大模型提示词（**不含** Key） |
| `defaultTargetLanguage`、`translateAutoCopy`、`speechRate`、`translateWindowPinnedByDefault` | 结果窗口选项 |

删除设置（用 `defaults` 而不是直接删文件：系统会缓存设置，直接删文件可能又被写回来）：

```bash
defaults delete local.velos.Velos
```

删除缓存和临时文件：

```bash
rm -rf ~/Library/Caches/local.velos.Velos ~/Library/Caches/local.velos.Velos.OCR "${TMPDIR}Velos"
```

## 第 4 步：删除翻译引擎的 Key（填过才有）

在线翻译引擎的 Key 存在「钥匙串」里，不在设置文件里：服务名 `local.velos.Velos.engines`，账户是「引擎.字段」（例如 `deepl.authKey`）。

- 用「钥匙串访问」App：搜索 `Velos 翻译引擎`，把找到的条目都删掉；或者
- 用命令（每次删一条，删到提示找不到为止）：

```bash
while security delete-generic-password -s local.velos.Velos.engines >/dev/null 2>&1; do :; done
```

Key 是你在各服务商那里申请的；不再使用的话，也可以到服务商的控制台里删除或停用它。

Apple 翻译的离线语言包是系统的，其他 App 也在用，卸载 Velos 不需要删；想删的话在 系统设置 › 通用 › 语言与地区 › 翻译语言 里管理。

> 改过保存位置、又想删除截图和录屏？先在删除设置**之前**查一下位置：
> `defaults read local.velos.Velos screenshotDirectoryPath` 和 `defaults read local.velos.Velos recordingDirectoryPath`
> （没有输出表示用的是默认位置）。

## 第 5 步：撤销系统权限

这些记录在 macOS 的权限数据库里，App 删掉后它们不再起作用，但仍会显示在列表里。

| 权限 | 在哪里移除 |
|---|---|
| 屏幕与系统录音 | 系统设置 › 隐私与安全性 › 屏幕与系统录音 → 选中 Velos → 点「−」 |
| 麦克风（如果授权过） | 系统设置 › 隐私与安全性 › 麦克风 → 关闭 Velos |
| 辅助功能（用过长截图的「自动滚动」才有） | 系统设置 › 隐私与安全性 › 辅助功能 → 选中 Velos → 点「−」 |
| 登录项（第 1 步忘了关） | 系统设置 › 通用 › 登录项与扩展 → 删除 Velos |

也可以用命令重置这几项权限（自动滚动的权限在命令里叫 PostEvent）：

```bash
tccutil reset ScreenCapture local.velos.Velos
```

```bash
tccutil reset Microphone local.velos.Velos
```

```bash
tccutil reset PostEvent local.velos.Velos
```

## 第 6 步：你自己的截图和录屏（自行决定）

这些是你的文件，卸载 Velos 不需要删除它们：

| 内容 | 默认位置 |
|---|---|
| 截图 | `~/Pictures/ScreenShots` |
| 录屏和导出的 GIF | `~/Movies/ScreenRecordings` |
| 在缩略图上「移到废纸篓」的录屏 / GIF | 废纸篓 |

## 确认已卸载干净

```bash
ls -d /Applications/Velos.app ~/Library/Preferences/local.velos.Velos.plist ~/Library/Caches/local.velos.Velos ~/Library/Caches/local.velos.Velos.OCR "${TMPDIR}Velos" 2>/dev/null; security find-generic-password -s local.velos.Velos.engines 2>/dev/null
```

没有任何输出就说明都删掉了。

## Velos 不会留下的东西

为了让你放心，下面这些位置 Velos **从不**创建，不用去找：

- `~/Library/Application Support`、`~/Library/Containers`、`~/Library/Saved Application State`、`~/Library/HTTPStorages`、`~/Library/Cookies` 里没有 Velos 的文件夹（`~/Library/Caches` 里只有上面第 3 步列出的两个）
- `~/Library/LaunchAgents`、`/Library/LaunchDaemons` 里没有 Velos 的文件（开机启动用的是系统的登录项机制，见第 1、5 步）
- 没有系统扩展、内核扩展、安装器收据、浏览器插件
- 默认不联网；只有你在设置里启用并填了 Key 的在线翻译引擎，才会把要翻译的文字发给那家服务商。Velos 自己没有服务器、没有账号，不收集任何数据

另外两点说明：

- **系统日志**：Velos 往 macOS 的系统日志里写过运行记录（只有操作和参数，不含画面或声音内容），由系统自动轮换清除，无需也无法单独删除。
- **剪贴板**：最后一次复制的截图会留在剪贴板里，直到你复制别的东西。

## 如果你从源码构建过

- 删除项目文件夹即可（里面的 `.build`、`build`、`dist` 都是编译产物）。
- 调试版的自测只把文件写在运行自测时指定的文件夹和 `$TMPDIR/VelosSelfTest` 里，另外会留下测试用的设置 `~/Library/Preferences/local.velos.uitest.plist`（`defaults delete local.velos.uitest` 删除）；正式版不会产生这些文件。

## 从旧版 Snap 升级后的清理

Velos 以前叫 Snap（内部标识 `local.snap.Snap`）。改名后 macOS 把 Velos 当成一个新 App，旧 Snap 的这些记录不会自动消失。它们不影响 Velos 使用，只是看着不干净，可以手动清掉：

1. **隐私权限列表**：系统设置 › 隐私与安全性 › 屏幕与系统录音、辅助功能、麦克风，在每个列表里选中「Snap」（以及「Snap 测试版」），点下面的「−」。macOS 不会因为删了 App 就清掉这些记录，App 自己也没有权限改，只能手动删。
2. **登录项**：系统设置 › 通用 › 登录项与扩展，选中「Snap」，点「−」。
3. **设置和缓存文件**（移到废纸篓即可）：
   - `~/Library/Preferences/local.snap.Snap.plist`（旧设置；Velos 第一次启动时已经搬过来了）
   - `~/Library/Preferences/local.snap.Snap.debug.plist`、`~/Library/Preferences/local.snap.uitest.plist`（只在从源码构建过测试版时才有）
   - `~/Library/Caches/local.snap.Snap`、`~/Library/Caches/local.snap.Snap.OCR`
4. **钥匙串里的翻译 Key**（填过才有）：打开「钥匙串访问」，搜索 `local.snap.Snap.engines`，删除找到的条目。Velos 不会读这些旧条目，需要的话在 Velos 的设置里重新填写。
