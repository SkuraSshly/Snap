# 卸载 Snap

Snap 不安装任何后台服务、系统扩展或安装器（截屏翻译用的文字识别小进程 SnapOCR 在 App 里面，随 App 一起删除）。下面列出了它在电脑上留下的**全部**内容，按顺序处理即可卸载干净。

## 第 1 步：关闭开机启动，退出 Snap

1. 菜单栏 Snap 图标 › 设置 › 通用 › **取消勾选「登录时自动启动」**（如果开过）。
   先在 Snap 里关掉，系统的登录项记录会被正常移除。
2. 菜单栏 Snap 图标 › **退出 Snap**。

菜单栏图标被隐藏了？在「应用程序」里双击 Snap 会打开设置窗口；退出也可以用：

```bash
osascript -e 'quit app "Snap"'
```

## 第 2 步：删除 App

把 `/Applications/Snap.app`（或你放 Snap 的位置）拖到废纸篓。

## 第 3 步：删除设置、缓存和临时文件

| 内容 | 位置 | 说明 |
|---|---|---|
| 设置 | `~/Library/Preferences/local.snap.Snap.plist` | 快捷键、保存位置、各项开关（含截屏翻译的设置，见下表） |
| 文字识别模型缓存 | `~/Library/Caches/local.snap.Snap`、`~/Library/Caches/local.snap.Snap.OCR` | 系统的 Vision 框架为截屏翻译编译的识别模型（几百 KB），由系统写入 |
| 拖拽用的临时文件 | `$TMPDIR/Snap`（`/var/folders/…/T/Snap`） | 只在把**未保存**的截图从缩略图拖出去时产生；Snap 每次启动会清理一天前的 |

截屏翻译在设置文件里的项目（都在 `local.snap.Snap` 里，上面的 `defaults delete` 会一起删掉）：

| 设置项 | 内容 |
|---|---|
| `translateHotkey` | 截屏翻译快捷键 |
| `hotkeysMigratedToASD` | 默认快捷键已换成 ⌥A / ⌥S / ⌥D 的标记 |
| `ocrSmartLayout`、`ocrDetectsQRCodes`、`ocrPreferredLanguage` | 文字识别选项 |
| `ocrFullWarmUpBuild` | 已为哪个系统版本预先编译过识别模型 |
| `enabledEngines`、`defaultEngine`、`llmPrompt` | 启用的在线引擎、默认引擎、大模型提示词（**不含** Key） |
| `defaultTargetLanguage`、`translateAutoCopy`、`speechRate`、`translateWindowPinnedByDefault` | 结果窗口选项 |

删除设置（用 `defaults` 而不是直接删文件：系统会缓存设置，直接删文件可能又被写回来）：

```bash
defaults delete local.snap.Snap
```

删除缓存和临时文件：

```bash
rm -rf ~/Library/Caches/local.snap.Snap ~/Library/Caches/local.snap.Snap.OCR "${TMPDIR}Snap"
```

## 第 4 步：删除翻译引擎的 Key（填过才有）

在线翻译引擎的 Key 存在「钥匙串」里，不在设置文件里：服务名 `local.snap.Snap.engines`，账户是「引擎.字段」（例如 `deepl.authKey`）。

- 用「钥匙串访问」App：搜索 `Snap 翻译引擎`，把找到的条目都删掉；或者
- 用命令（每次删一条，删到提示找不到为止）：

```bash
while security delete-generic-password -s local.snap.Snap.engines >/dev/null 2>&1; do :; done
```

Key 是你在各服务商那里申请的；不再使用的话，也可以到服务商的控制台里删除或停用它。

Apple 翻译的离线语言包是系统的，其他 App 也在用，卸载 Snap 不需要删；想删的话在 系统设置 › 通用 › 语言与地区 › 翻译语言 里管理。

> 改过保存位置、又想删除截图和录屏？先在删除设置**之前**查一下位置：
> `defaults read local.snap.Snap screenshotDirectoryPath` 和 `defaults read local.snap.Snap recordingDirectoryPath`
> （没有输出表示用的是默认位置）。

## 第 5 步：撤销系统权限

这些记录在 macOS 的权限数据库里，App 删掉后它们不再起作用，但仍会显示在列表里。

| 权限 | 在哪里移除 |
|---|---|
| 屏幕与系统录音 | 系统设置 › 隐私与安全性 › 屏幕与系统录音 → 选中 Snap → 点「−」 |
| 麦克风（如果授权过） | 系统设置 › 隐私与安全性 › 麦克风 → 关闭 Snap |
| 登录项（第 1 步忘了关） | 系统设置 › 通用 › 登录项与扩展 → 删除 Snap |

也可以用命令重置这两项权限：

```bash
tccutil reset ScreenCapture local.snap.Snap
```

```bash
tccutil reset Microphone local.snap.Snap
```

## 第 6 步：你自己的截图和录屏（自行决定）

这些是你的文件，卸载 Snap 不需要删除它们：

| 内容 | 默认位置 |
|---|---|
| 截图 | `~/Pictures/ScreenShots` |
| 录屏和导出的 GIF | `~/Movies/ScreenRecordings` |
| 在缩略图上「移到废纸篓」的录屏 / GIF | 废纸篓 |

## 确认已卸载干净

```bash
ls -d /Applications/Snap.app ~/Library/Preferences/local.snap.Snap.plist ~/Library/Caches/local.snap.Snap ~/Library/Caches/local.snap.Snap.OCR "${TMPDIR}Snap" 2>/dev/null; security find-generic-password -s local.snap.Snap.engines 2>/dev/null
```

没有任何输出就说明都删掉了。

## Snap 不会留下的东西

为了让你放心，下面这些位置 Snap **从不**创建，不用去找：

- `~/Library/Application Support`、`~/Library/Containers`、`~/Library/Saved Application State`、`~/Library/HTTPStorages`、`~/Library/Cookies` 里没有 Snap 的文件夹（`~/Library/Caches` 里只有上面第 3 步列出的两个）
- `~/Library/LaunchAgents`、`/Library/LaunchDaemons` 里没有 Snap 的文件（开机启动用的是系统的登录项机制，见第 1、5 步）
- 没有系统扩展、内核扩展、安装器收据、浏览器插件
- 默认不联网；只有你在设置里启用并填了 Key 的在线翻译引擎，才会把要翻译的文字发给那家服务商。Snap 自己没有服务器、没有账号，不收集任何数据

另外两点说明：

- **系统日志**：Snap 往 macOS 的系统日志里写过运行记录（只有操作和参数，不含画面或声音内容），由系统自动轮换清除，无需也无法单独删除。
- **剪贴板**：最后一次复制的截图会留在剪贴板里，直到你复制别的东西。

## 如果你从源码构建过

- 删除项目文件夹即可（里面的 `.build`、`build`、`dist` 都是编译产物）。
- 调试版的自测只把文件写在运行自测时指定的文件夹和 `$TMPDIR/SnapSelfTest` 里，另外会留下测试用的设置 `~/Library/Preferences/local.snap.uitest.plist`（`defaults delete local.snap.uitest` 删除）；正式版不会产生这些文件。
