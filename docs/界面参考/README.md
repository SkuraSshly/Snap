# Velos 界面参考（给 Windows 版用）

这里是 Mac 版 Velos 2.1.2 的界面截图和可以共用的资源。Windows 版的每个界面都要照着这里做：布局、配色、圆角、间距、图标风格和文字都尽量保持一致。截图看不清细节的时候（尺寸、圆角半径、字号、动画），以 `Sources/Velos` 里对应的代码为准，下面写了每个界面的代码在哪里。

截图里的背景都是 Velos 自测时画出来的：灰色渐变加色块的合成画面，或者演示用的桌面。这些背景不是界面的一部分，不用照做。

## 设置（`设置/` 浅色，`设置-深色/` 深色，代码在 `Settings/`）

`settings-<页>.png` 是这一页的顶部，`-bottom` 是滚到底部的样子。`onboarding` 是第一次运行时的权限引导窗口。Windows 上权限引导大多用不上，可以改成简单的欢迎页。

Windows 版也要跟随系统的浅色和深色模式，两套配色分别照着 `设置/` 和 `设置-深色/` 做。

## 资源（`资源/`）：可以直接用

- `App图标/icon-*.png`：App 图标，16～1024 像素各一张，用来生成 Windows 的 .ico（至少包含 16、24、32、48、64、256）。图形由 `scripts/make-icon.swift` 用代码画出。
- `图标/托盘图标-黑-*x.png`、`托盘图标-白-*x.png`：托盘图标，前倾的「V」，18×18 点，1x/2x/3x 三种。浅色任务栏用黑色，深色任务栏用白色。
- `图标/长截图图标-*x.png`：截图工具栏上「长截图」按钮的剪刀图标，18×18 点，模板图，按按钮颜色上色。
- `图标/字标-Velos-*x.png`：设置窗口左上角的字标。也可以照 `Sources/Velos/UI/VelosIcons.swift` 里的 `VelosWordmark` 重新画：圆体粗字、向前倾斜、渐变色，加一道扫描线和几颗光点。

**系统图标不能照搬。** Mac 版的按钮图标大多是 Apple 的 SF Symbols，按授权规定只能在 Apple 的系统上用，不能拷进 Windows 版。Windows 版请用系统自带的图标字体：Windows 11 用 **Segoe Fluent Icons**，Windows 10 用 **Segoe MDL2 Assets**。选形状最接近的图标，保持线条粗细一致。Mac 版用到的 SF Symbols 名字如下，可以按名字去找对应的图标：

`camera.viewfinder`（截图）· `record.circle`（录屏）· `character.bubble`（翻译）· `gearshape.fill`（通用）· `keyboard.fill`（快捷键）· `rectangle.fill` / `circle.fill` / `arrow.up.right` / `line.diagonal` / `drop.halffull` / `t.square` / `1.circle` / `checkerboard.rectangle`（标注工具）· `arrow.uturn.backward` / `arrow.uturn.forward`（撤销、重做）· `pin.fill`（钉图）· `square.and.arrow.down`（保存）· `doc.on.doc`（复制）· `xmark`（关闭）· `checkmark`（完成）· `mic.fill` / `mic.slash`（麦克风）· `pause.fill` / `play.fill` / `stop.fill`（暂停、继续、停止）· `speaker.wave.2.fill`（朗读）· `arrow.left.arrow.right`（交换语言）· `folder.fill`（保存位置）· `power`（开机启动）· `trash`（删除）· `film.stack`（GIF）· `timer`（倒计时）· `cursorarrow.click.2`（点击高亮）
