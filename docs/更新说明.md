# 更新说明

## Velos 2.2

### 新功能
- 圆角截图：选好区域后，尺寸标签右边有「圆角」拉条（0–40 点），选区直接显示圆角的样子；截出来的图圆角外透明（PNG、HEIC 保留透明，JPEG 填白色），大小会记住
- 长截图的「自动滚动」回来了：点一下就一直开着，鼠标在选区里就匀速慢慢往下滚，移出选区暂停、移回来立刻接着滚，滚到底或到长度上限自动停。需要「辅助功能」权限，只在用自动滚动时请求

### 改进
- 长截图重写为只看画面拼接，完全不碰你的滚动（鼠标、触控板、各种滚动工具都照常）；滚得太快跟丢后自动接回
- 长截图的起点是开始滚动那一刻的画面；拼接时不会把调度中心、切换桌面的过渡画面接进去，回来后接着拼
- 半透明的标题栏、两侧不动的边栏只出现一次；提示条不再被截进长图
- 全屏模式（⌥A 后切到全屏）也能长截图
- 实时预览更清晰、跟手
- 去掉长截图的横向模式和「竖向 / 横向」切换
- 编辑窗口里圆角图片的四角显示编辑窗口的背景色，只用投影区分图片和背景
- 拉条的白点、选区和标注的控制点上，鼠标变成暖色的一对小三角（控制点上朝外的深、朝里的浅），和 Velos 的配色一致

### 内部改进（不影响使用）
- 自绘光标共用一套画法和配色；数值拉条拆成单独的文件；清理长截图横向模式留下的代码

## Velos 2.1.2

### 改进
- 编辑窗口可以拖边缘调整大小、用绿色按钮缩放，⌘M 最小化；拉动窗口时图片跟着缩放并居中（手动缩放后不再跟随，⌘0 恢复），窗口边缘显示调整大小的箭头
- 长截图：左右不动的边栏里有一直在变的小东西（转圈图标、闪烁的光标）时，也能认出是固定边栏，不再一段段重复拼上
- 设置窗口和权限设置窗口每次打开都在最上面，并出现在当前所在的桌面（包括全屏 App 上面）；最小化了会自动恢复
- 设置窗口左上角换成图标配色的「Velos」字标，去掉底部的版本落款
- 视频预览窗口有最小尺寸

### 内部改进（不影响使用）
- 菜单栏图标改用 sRGB 绘制
- 调试版的翻译 Key 存在单独的钥匙串条目里，不会碰到正式版的 Key
- 文档按实测更新下载大小（约 3 MB）和空闲内存（约 14–50 MB）

## Velos 2.1.1

### 修复
- 长截图：滚动后刚露出的内容还没画完（一片空白）时，画好后不会再换上，空白留在了拼好的长图里——这是 2.1 带出来的问题，已修复

### 内部改进（不影响使用）
- 编辑窗口里按着 ⌘ / ⌥ / ⌃ 的方向键不再移动标注，和截图界面一致
- 代码整理：截图界面和编辑窗口共用一套标注按键；前台 App 切换、工具栏位置等从截图界面拆出；大文件按职责拆分
- 新增单元测试（./test.sh），覆盖长截图拼接、GIF 编码、快捷键、翻译引擎签名、文字识别等

## Velos 2.1

### 改动
- 去掉长截图的「自动滚动」：在各种 App 里表现不稳定，常常提前停下、画面不流畅。长截图改为只用手动滚动，控制条和设置里的相关选项一并去掉
- 滚动限速保留：快速滚动时自动放慢，滚多快都不漏内容（需要「辅助功能」权限，不给也能用，只是要滚慢一点）

### 改进
- 长截图在高刷屏（例如 240Hz 外接屏）上更流畅：截取最多每秒 60 帧，不再跟着屏幕刷新率把主线程塞满
- 长截图选区里大部分区域不动（例如框了整个窗口、只有中间一栏在滚）时，拼接不再把真实的滚动误判成「没动」

## Velos 2.0

**Snap 改名为 Velos**（希腊语「箭」）。App 名、菜单、设置、安装包、GitHub 仓库都已改名。第一次打开 Velos 会自动搬来 Snap 的设置；系统权限需要给 Velos 重新打开一次（旧 Snap 的残留清理见卸载说明）。

### 新功能

**截屏翻译（⌥D）**
- 框选后离线识别文字（系统自带的 Vision，在单独的小进程里识别，空闲 30 秒自动退出），用 Apple 翻译离线翻译，译文逐段显示
- 结果窗口：可以改原文、换语言、交换语言、朗读；钉住后置顶、可拖动和调整大小、可以同时钉住多个
- 单个单词或短语查 macOS 自带的词典
- 可选的在线翻译引擎：有道、DeepL、微软、百度、腾讯、火山、OpenAI 兼容的大模型、Claude（默认全部关闭；Key 存在钥匙串里）
- 设置里需要 Key 的引擎合成一项「在线翻译」：选服务商、填 Key、打开开关，不再一长串列出来
- 设置：优先识别的语言、智能排版、识别二维码、默认目标语言、翻译完成后自动复制、朗读语速、默认钉住

**长截图**（截图工具栏上的剪刀按钮）
- 框选区域后滚动页面，Velos 边滚边拼接；支持竖向、横向
- 顶部标题栏、底部输入框只出现一次；左右不动的边栏不会一段段重复；滚动时浮出的滚动条不影响拼接；刚滚到时没画完的内容会自动换成画好的
- 滚动限速（快速滚动时自动放慢，滚多快都不漏）——需要「辅助功能」权限；装了 Mos 之类平滑滚动工具也能用
- Esc 随时取消；最长 20000 像素

**标注**
- 选中后拖控制点调整大小（矩形、椭圆、马赛克、模糊的 8 个控制点，直线、箭头的两个端点；按住 Shift 等比、45°）
- 鼠标在标注上显示四向移动光标，按住直接拖动
- 粗细、宽度、字号、大小、强度改成拉条，精确到 1 点
- 矩形、椭圆可以选实心；文字可以加底色（底色用所选颜色，文字自动变白 / 黑）
- 标注按选区裁剪显示，和输出的图片一致

**编辑窗口（单击缩略图打开）**
- 按住 ⌥ 滚动或双指捏合缩放（滚轮每格 15%，最大 400%），显示当前比例；⌘= / ⌘- / ⌘0
- 长截图按原像素宽度打开，上下滚动查看，右侧（横向在下方）有滚动条
- 图片浮在暖色底上，边界清楚；标注只能画在图片里

**钉图**
- 长截图钉到屏幕上时只露出一段，滚轮在窗口里翻看，⌥ + 滚轮缩放
- 长截图控制条上可以直接「编辑」或「钉图」

**录屏**
- 录制中用 Velos 截图、截屏翻译，界面会录进视频（录屏自己的控制条、红框除外）

### 改进
- 新的 App 图标和菜单栏图标：纸白底上一个前倾的「V」，框选的那一块像刚截下来的截图一样浮起来，旁边一个截图十字光标；小尺寸用清晰版，Dock、访达里不糊
- 设置里的输入框可以用 ⌘C / ⌘V / ⌘X / ⌘A / ⌘Z 复制粘贴了
- 设置侧栏左上角改为图标 + 名字一行
- 设置窗口可以拖边缘调整大小、用绿色按钮缩放（最小 800×600）；⌘Q 退出 Velos
- 图标在所有尺寸都保持锐利：不再虚化选区外的画面，V 颜色更饱满
- 打开设置时左上角不再单独飞入；去掉侧栏底部的版本文字（版本号在「通用」页）
- 默认快捷键改为 ⌥A 截图、⌥S 录屏、⌥D 截屏翻译（还在用旧默认 ⌥1 / ⌥2 的会自动换过来）
- 选着标注工具时也能拖选区的控制点调整截图范围
- 长截图在 Retina 屏上更稳：按屏幕原生色彩截取、细微差别也能对上，快速滚动不丢内容
- 长截图的缩略图出现在截图所在的屏幕，长图缩略图够宽，按钮不再挤在一起
- 设置窗口改为左侧栏目、右侧设置；新增「截屏翻译」页、辅助功能权限、长截图设置、录屏转 GIF、保存位置的「打开」按钮
- 颜色统一到暖色主题：截图用杏色、录屏用珊瑚红、截屏翻译用鼠尾草绿
- 菜单栏只留截图、录屏、截屏翻译、设置、退出
- 一级窗口出现在屏幕中间，二级窗口出现在一级窗口中间
- 设置、编辑等 Velos 自己的普通窗口也可以被截图、录屏、截屏翻译

### 隐私
- 仍然默认不联网：截图、录屏、文字识别、Apple 翻译、查词都在本机完成。只有你在设置里启用并填了 Key 的在线翻译引擎，才会把要翻译的文字发给那家服务商
- 新的可选权限：「辅助功能」，只在长截图的滚动限速时使用
