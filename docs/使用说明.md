# Velos 使用说明

Velos 是一个轻量的 macOS 截图与录屏工具，常驻菜单栏，用快捷键唤起。

- 不联网、不收集任何数据、不自动更新
- 体积约 2.4 MB，空闲时内存约 13 MB、CPU 0%
- 空闲时不运行任何屏幕采集；Velos 自己的界面不会出现在截图和录屏里

## 系统要求

macOS 15 或更新，Apple 芯片的 Mac。

## 安装

1. 打开 `Velos-2.1.dmg`，把 **Velos** 拖到旁边的「应用程序」文件夹。
2. 在「应用程序」里打开 Velos。第一次运行会出现权限引导：
   - **屏幕与系统录音**（必需）：截图和录屏都需要。授权后按引导重新打开 Velos。
   - **麦克风**（可选）：只有录屏时要录自己的声音才需要。
3. 想开机自动运行：菜单栏图标 › 设置 › 通用 › 勾选「登录时自动启动」。

> **移动过 Velos.app 的位置？** 登录项记录的是 App 所在的位置。把 Velos 换到别的文件夹后，
> 请在设置里把「登录时自动启动」关掉再打开一次，让它指向新位置。

> **拷到其他 Mac 上用？** 这个版本使用本机签名（ad-hoc），没有经过 Apple 公证。
> 在别的 Mac 上第一次打开时 macOS 会拦下，需要到 系统设置 › 隐私与安全性 里点「仍要打开」。
> 要让别人直接打开，需要 Apple 开发者账号（每年 99 美元）签名并公证。

## 快捷键

| 场合 | 按键 | 作用 |
|---|---|---|
| 任何时候 | ⌥A | 截图 |
| 任何时候 | ⌥S | 录屏；录制中再按一次 = 停止 |
| 任何时候 | ⌥D | 截屏翻译 |
| 截图 / 录屏 / 截屏翻译选区 | 再按 ⌥A / ⌥S / ⌥D | 在「区域 ↔ 全屏」之间切换（按住 ⌥ 连按也行） |
| 截图界面 | Enter | 完成（按设置复制到剪贴板、显示缩略图） |
| 截图界面 | ⌘S | 完成并保存到文件 |
| 截图界面 | ⌘Z / ⇧⌘Z | 撤销 / 重做标注 |
| 截图界面 | C | 拷贝放大镜下的颜色值 |
| 截图 / 录屏选区 | 方向键（⇧ + 方向键） | 微调选区 1 像素（10 像素） |
| 截图 / 录屏选区 | Esc | 取消（正在输入文字时先结束输入） |
| 录屏倒计时 | Esc / Enter | 取消 / 立即开始 |
| 钉图 | 单击选中后 Esc 或双击 | 关闭钉图 |
| 钉图 | 滚轮或双指捏合 / ⌘ + 滚轮 | 缩放 / 调整透明度 |
| 钉图 | ⌘C | 拷贝钉图 |
| 翻译结果窗口 | ⌘C / ⇧⌘C | 复制译文 / 复制原文 |
| 翻译结果窗口 | ⌘R / ⌘P / Esc | 重新翻译 / 钉住或取消钉住 / 关闭 |

快捷键可以在 设置 › 快捷键 里修改。已被 macOS 占用的组合（如 ⇧⌘3、⌘空格）按下时由系统直接处理，Velos 收不到，不能设置。

## 功能

**截图**：冻结画面后框选；自动识别窗口；放大镜；拖动控制点调整；标注工具（矩形、椭圆、箭头、直线、画笔、荧光笔、文字、序号、马赛克、模糊，按住 ⇧ 画正方形、正圆，或沿 45° 整数倍方向的直线和箭头；颜色、不透明度、粗细 / 字号 / 强度都可以在属性栏的拉条上精确调整，每种工具各自记住上次的设置）；钉在屏幕上；以 Retina 原生像素输出并写入色彩配置文件。

**截图之后**：右下角出现缩略图——单击继续编辑（编辑窗口里按住 ⌥ 滚动或双指捏合缩放，滚轮每格 15%，缩放时显示比例，100% 是原像素，最大 400%；放大后滚动查看各处；⌘= 放大、⌘- 缩小、⌘0 回到原来大小），拖进任何 App，点「保存」存为文件，或钉在屏幕上。粘贴过的截图缩略图会自动收起。**只有点「保存」或按 ⌘S 才会写文件**。

**录屏**：区域或全屏；HEVC / H.264 硬件编码；系统声音与麦克风实时混成一条 AAC 音轨（48kHz、256kbps、立体声）；暂停 / 继续（暂停的部分不在视频里）；浮动控制条与红框（都不会被录进去）；3 秒倒计时；鼠标点击高亮（会录进视频）。录制中可以照常按 ⌥A 截图、⌥D 截屏翻译，截图界面、标注、翻译结果、缩略图、钉图都会录进视频（录的就是屏幕上看到的），只有录屏自己的控制条和红框不录。

**长截图**：按 ⌥A 框选要截的区域（例如聊天窗口的消息区、网页正文），点工具栏的「长截图」（剪刀图标，在钉图、保存的左边，要在画标注之前）。截图界面关闭后，选区外变暗、选区有杏色边框，鼠标和滚轮照常交给下面的 App：在选区里滚动页面，Velos 边滚边拼接，旁边有实时预览，控制条上显示已拼接的长度。开始时只出一条提示，之后的过程中不再出提示。
- 竖向 / 横向：控制条上切换（切换后从头开始）
- 往回滚不会重复拼接
- 滚动速度：第一次长截图时会请求「辅助功能」权限。允许后，长截图期间选区里的滚动限制在合适的速度（每秒最多约 7.5 个选区高度，最快每秒 4000 点）——一下甩得再快，也分几次小段滚过去，不会漏掉内容；结束后恢复正常。不允许也能用，只是要滚慢一点
- 准确：按屏幕刷新率截取（60 / 120 帧）；滚动时浮出的滚动条不影响拼接；文字有细微差别也能对上；刚滚到时还没画完的内容（空白、模糊），画好后会自动换上
- 顶部固定的标题栏、底部固定的输入框只出现一次；左右不滚动的边栏（例如会话列表）只保留第一屏，往下用边栏的背景色延伸，不会一段段重复
- 点开长截图的缩略图：按原像素宽度显示，上下滚动查看；按住 ⌥ 往下滚可以缩小到看全整张
- 最长 20000 像素（Retina 屏上约 10000 点）
- 点「完成」：和普通截图一样复制到剪贴板、显示缩略图（可以继续标注、保存、钉图）；点编辑图标直接打开编辑窗口继续标注；点钉图图标把整张长图钉在屏幕上；点保存图标直接存文件；点 ✕ 或按 Esc 取消
- 编辑窗口里图片浮在暖色底上（带投影），一眼看清边界；标注只能画在图片里；长截图右侧（横向在下方）有滚动条

**截屏翻译**：按 ⌥D 框选，松开鼠标后结果窗口立即出现，识别出的原文和译文随后填进来（长文逐段显示）。文字识别完全离线；默认用 Apple 翻译（离线、免费，第一次用某对语言时系统会提示下载语言包）。原文可以直接修改，停顿后自动重新翻译；可以换语言、交换语言、朗读。单个单词或短语会查 macOS 自带的词典（「词典」App 里启用的那些）。点 📌 钉住后窗口置顶、可拖动和调整大小，可以同时钉住多个。
在 设置 › 截屏翻译 里可以：选优先识别的语言、智能排版、识别二维码；设默认目标语言（默认中文译成英文、其他译成简体中文）、翻译完成后自动复制译文、朗读语速、默认钉住；在「在线翻译」一项里选服务商（腾讯、火山、百度、有道、DeepL、微软，或 OpenAI 兼容大模型、Claude），填写自己的 Key（保存在钥匙串里）、打开开关并测试；可以逐个启用多个，下拉菜单里已启用的带 ✓。想免费用可以选腾讯翻译君、火山翻译（每月有免费额度），或在大模型里填智谱的免费模型 glm-4-flash（Base URL `https://open.bigmodel.cn/api/paas/v4`）。默认引擎失败时会自动换到下一个可用的引擎，并在译文下面说明。

**录屏之后**：右下角出现录屏缩略图——单击预览，拖进任何 App，拷贝文件，导出 GIF，移到废纸篓。以前的录屏可以在 设置 › 录屏 › GIF 里点「选择录屏…」转换。

## 文件保存在哪

| 内容 | 默认位置 | 何时写入 |
|---|---|---|
| 截图 | `~/Pictures/ScreenShots` | 点缩略图上的「保存」或按 ⌘S 时 |
| 录屏 | `~/Movies/ScreenRecordings` | 录制时自动写入 |
| GIF | 与对应的录屏放在一起 | 点「GIF」导出时 |

位置可以在 设置 › 通用 里修改。Velos 写到电脑上的全部文件见《卸载说明》。

## 隐私

- **默认不联网**：截图、录屏、文字识别、Apple 翻译、查词都在本机完成。只有你在 设置 › 截屏翻译 里启用并填了 Key 的在线翻译引擎，才会把要翻译的文字（不是截图）发给那家服务商；关掉引擎就不再联网。
- **不收集数据**：没有统计、没有崩溃上报、没有账号。
- **不自动更新**。
- 运行日志写在系统日志里（只有操作和参数，例如「开始录制：2560×1440，60 fps」，不含任何画面或声音内容），由系统自动清理。查看：
  `log show --predicate 'subsystem == "local.velos.Velos"' --last 1h`

## 已知限制

- **macOS 会定期弹出「Velos 正在访问你的屏幕」的确认框**（大约每月一次或系统更新后）。这是 macOS 15 对所有录屏类 App 的系统行为，App 无法关闭。
- **系统快捷键不能设为 Velos 的快捷键**（见上文）。
- 菜单栏菜单、钉图右键菜单是系统原生菜单，无法改成温暖风格。
- GIF 每帧最多 256 色：界面演示效果很好，大面积渐变和照片会有色带。
- 用 AirPods 等蓝牙耳机的麦克风录音时，macOS 会把耳机切到通话模式，系统声音的音质随之下降；用 Mac 自带麦克风不会。

## 从源码构建

需要 Xcode 命令行工具（`xcode-select --install`），不需要 Xcode，也没有任何第三方依赖。

| 命令 | 作用 |
|---|---|
| `./build.sh` | 编译 release 版，生成 `build/Velos.app` |
| `./build.sh debug` | 编译调试版（包含自测代码） |
| `./run.sh` | 编译并重新启动 Velos |
| `./package.sh` | 编译并打包成 `dist/Velos-版本号.dmg` 和 `.zip` |
| `swiftc scripts/make-icon.swift -o /tmp/make-icon && /tmp/make-icon Resources/AppIcon.icns` | 重新生成 App 图标 |

源码在 `Sources/Velos`，按功能分文件夹：`Capture`（调度、冻屏）、`Overlay`（选区界面）、`Screenshot`、`Annotation`（标注）、`Pin`（钉图）、`Thumbnail`（缩略图）、`Recording`（录屏、混音、GIF）、`Hotkeys`、`MenuBar`、`Settings`、`Permissions`、`UI`（温暖风格控件）、`Utilities`。
