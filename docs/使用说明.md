# Snap 使用说明

Snap 是一个轻量的 macOS 截图与录屏工具，常驻菜单栏，用快捷键唤起。

- 不联网、不收集任何数据、不自动更新
- 体积约 2.4 MB，空闲时内存约 13 MB、CPU 0%
- 空闲时不运行任何屏幕采集；Snap 自己的界面不会出现在截图和录屏里

## 系统要求

macOS 15 或更新，Apple 芯片的 Mac。

## 安装

1. 打开 `Snap-1.0.0.dmg`，把 **Snap** 拖到旁边的「应用程序」文件夹。
2. 在「应用程序」里打开 Snap。第一次运行会出现权限引导：
   - **屏幕与系统录音**（必需）：截图和录屏都需要。授权后按引导重新打开 Snap。
   - **麦克风**（可选）：只有录屏时要录自己的声音才需要。
3. 想开机自动运行：菜单栏图标 › 设置 › 通用 › 勾选「登录时自动启动」。

> **移动过 Snap.app 的位置？** 登录项记录的是 App 所在的位置。把 Snap 换到别的文件夹后，
> 请在设置里把「登录时自动启动」关掉再打开一次，让它指向新位置。

> **拷到其他 Mac 上用？** 这个版本使用本机签名（ad-hoc），没有经过 Apple 公证。
> 在别的 Mac 上第一次打开时 macOS 会拦下，需要到 系统设置 › 隐私与安全性 里点「仍要打开」。
> 要让别人直接打开，需要 Apple 开发者账号（每年 99 美元）签名并公证。

## 快捷键

| 场合 | 按键 | 作用 |
|---|---|---|
| 任何时候 | ⌥A | 截图 |
| 任何时候 | ⌥S | 录屏；录制中再按一次 = 停止 |
| 任何时候 | ⌥D | 截屏翻译（目前先识别文字，翻译功能开发中） |
| 截图 / 录屏 / 截屏翻译选区 | 再按 ⌥A / ⌥S / ⌥D | 在「区域 ↔ 全屏」之间切换（按住 ⌥ 连按也行） |
| 截图界面 | Enter | 完成（按设置复制到剪贴板、显示缩略图） |
| 截图界面 | ⌘S | 完成并保存到文件 |
| 截图界面 | ⌘Z / ⇧⌘Z | 撤销 / 重做标注 |
| 截图界面 | C | 拷贝放大镜下的颜色值 |
| 截图 / 录屏选区 | 方向键（⇧ + 方向键） | 微调选区 1 像素（10 像素） |
| 截图 / 录屏选区 | Esc | 取消（正在输入文字时先结束输入） |
| 录屏倒计时 | Esc / Enter | 取消 / 立即开始 |
| 钉图 | 单击选中后 Esc 或双击 | 关闭钉图 |
| 钉图 | 滚轮或双指捏合 / ⌘ + 滚轮 | 缩放 / 调整透明度 |
| 钉图 | ⌘C | 拷贝钉图 |

快捷键可以在 设置 › 快捷键 里修改。已被 macOS 占用的组合（如 ⇧⌘3、⌘空格）按下时由系统直接处理，Snap 收不到，不能设置。

## 功能

**截图**：冻结画面后框选；自动识别窗口；放大镜；拖动控制点调整；标注工具（矩形、椭圆、箭头、直线、画笔、荧光笔、文字、序号、马赛克、模糊，按住 ⇧ 画正方形、正圆，或沿 45° 整数倍方向的直线和箭头）；钉在屏幕上；以 Retina 原生像素输出并写入色彩配置文件。

**截图之后**：右下角出现缩略图——单击继续编辑，拖进任何 App，点「保存」存为文件，或钉在屏幕上。粘贴过的截图缩略图会自动收起。**只有点「保存」或按 ⌘S 才会写文件**。

**录屏**：区域或全屏；HEVC / H.264 硬件编码；系统声音与麦克风实时混成一条 AAC 音轨（48kHz、256kbps、立体声）；暂停 / 继续（暂停的部分不在视频里）；浮动控制条与红框（都不会被录进去）；3 秒倒计时；鼠标点击高亮（会录进视频）。

**录屏之后**：右下角出现录屏缩略图——单击预览，拖进任何 App，拷贝文件，导出 GIF，移到废纸篓。旧的录屏可以用菜单栏「将录屏转为 GIF…」转换。

## 文件保存在哪

| 内容 | 默认位置 | 何时写入 |
|---|---|---|
| 截图 | `~/Pictures/ScreenShots` | 点缩略图上的「保存」或按 ⌘S 时 |
| 录屏 | `~/Movies/ScreenRecordings` | 录制时自动写入 |
| GIF | 与对应的录屏放在一起 | 点「GIF」导出时 |

位置可以在 设置 › 通用 里修改。Snap 写到电脑上的全部文件见《卸载说明》。

## 隐私

- **不联网**：程序里没有任何网络代码，也不链接网络相关的框架。
- **不收集数据**：没有统计、没有崩溃上报、没有账号。
- **不自动更新**。
- 运行日志写在系统日志里（只有操作和参数，例如「开始录制：2560×1440，60 fps」，不含任何画面或声音内容），由系统自动清理。查看：
  `log show --predicate 'subsystem == "local.snap.Snap"' --last 1h`

## 已知限制

- **macOS 会定期弹出「Snap 正在访问你的屏幕」的确认框**（大约每月一次或系统更新后）。这是 macOS 15 对所有录屏类 App 的系统行为，App 无法关闭。
- **系统快捷键不能设为 Snap 的快捷键**（见上文）。
- 菜单栏菜单、钉图右键菜单是系统原生菜单，无法改成温暖风格。
- GIF 每帧最多 256 色：界面演示效果很好，大面积渐变和照片会有色带。
- 用 AirPods 等蓝牙耳机的麦克风录音时，macOS 会把耳机切到通话模式，系统声音的音质随之下降；用 Mac 自带麦克风不会。

## 从源码构建

需要 Xcode 命令行工具（`xcode-select --install`），不需要 Xcode，也没有任何第三方依赖。

| 命令 | 作用 |
|---|---|
| `./build.sh` | 编译 release 版，生成 `build/Snap.app` |
| `./build.sh debug` | 编译调试版（包含自测代码） |
| `./run.sh` | 编译并重新启动 Snap |
| `./package.sh` | 编译并打包成 `dist/Snap-版本号.dmg` 和 `.zip` |
| `swiftc scripts/make-icon.swift -o /tmp/make-icon && /tmp/make-icon Resources/AppIcon.icns` | 重新生成 App 图标 |

源码在 `Sources/Snap`，按功能分文件夹：`Capture`（调度、冻屏）、`Overlay`（选区界面）、`Screenshot`、`Annotation`（标注）、`Pin`（钉图）、`Thumbnail`（缩略图）、`Recording`（录屏、混音、GIF）、`Hotkeys`、`MenuBar`、`Settings`、`Permissions`、`UI`（温暖风格控件）、`Utilities`。
